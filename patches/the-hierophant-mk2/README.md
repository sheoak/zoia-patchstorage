# The Hierophant MKII — The Akashic Delay

Stereo in, stereo out. A rebuild of [the original](../the-hierophant), which
carries on in mono alongside it — the two are separate branches, not successive
versions of one patch.

A delay built around two gestures that meet. Confessional mutes the input and
leaves the existing echoes running on alone; Recitation boost swells the feedback
and leaves it swollen. Together they turn a phrase you have stopped playing into
something that keeps growing.

What the rebuild changed: a Ghostverb where the Heretic Overdrive was, six clock
divisions named as note values rather than as multiply-and-divide pairs, MIDI
sync reduced to on or off, and a tape mode so the repeats darken as they go.

Played and documented at [zoiatheca](https://github.com/sheoak/zoiatheca).
